再深入：怎样用式子表示和检验？

同一个质量m、同一个高度零点：重力势能 Eₚ = mgh，动能 Eₖ = ½mv²。只有重力做功、导轨约束不做功时，Eₚ + Eₖ 保持不变。

静止释放后，下降Δh：mgΔh 与 ½mv² 应当相等。纸带实验用相邻点的位置和时间独立量出v，再比较这两项；不是先用守恒算速度再“证明”守恒。

如果存在本模拟的固定阻力F，走过路程s会把 Fs 的机械能转为内能；高度差Δh和沿轨道的路程s不是同一个量。

不要求背标准话。你的解释会保留，但不会仅凭填写就判断“已掌握”。

看能量去哪里了

浅蓝代表与高度相关的重力势能，绿色代表动能，橙色代表阻力和刹车转成的内能。第一次观察后再认识这些名称，不必先背公式才能试。

真正量一量

工坊里先通电，再放开重物。纸带每 0.02 秒记一个点，选三个相邻点比较速度与高度。读数来自模拟，不是真实仪器测量。

这次物理模型的边界

这是沿固定导轨运动的滑车模型，质量包含角色与滑板，忽略轮子转动能，不会脱轨；水膜、毛绒、左右平衡是视觉表现，没有额外推进力。所有高度以同一零面计算。暂停、录像帧率和模型时间不混为一谈。
