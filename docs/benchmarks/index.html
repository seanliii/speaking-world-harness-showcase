已观测 · 实验额度

很多任务先耗尽了时间和调用。

170 次运行/交付失败中，88 次触及时间限额，48 次触及调用或 token 停止线，其余 34 次需继续逐条核查。

这是相同资源限额下的结果，不是对“无限时间能否做对”的判断。没有正常交卷时，不把尚未评分的内容武断地说成答错。

把条件写清楚，比较才有意义。

考卷、模型与执行方式
  • GAIA 12、BrowseComp 8、SimpleQA 8、HumanEval 4；固定随机种子 20261030，全员使用同一份冻结题单。GAIA仅无附件题，BC来自历史40题集合，SimpleQA允许搜索。
  • 固定 DeepSeek V4.1 Flash 别名通路：出站请求 deepseek-v4-flash，回执 deepseek-flash / deepseek-v4-flash。这是请求与服务回执核验，不是远端权重认证。
  • 单家走军团原生接入；四模式走真实 HTTP 入口和隔离身份。保留各家原生工具和提示词，不手写一套替代答题流程，也不是上游各家最佳配置排行榜。
  • 单家并发 9，模式并发 3，上游模型连接合计最多 9。每单 240 秒、48 次模型请求、总输出 32768、单次输出 4096 token。输入累计524288后拒绝新请求，在途仍可能越线；共享检索入口最多24次。
判分与公平性限制
  • GAIA用确定性官方评分逻辑；代码真实运行隐藏测试；BC/SimpleQA用官方模板和本次指定模型判分，不是两个不同模型的独立盲评。
  • 416次均已判分，未评分0。不能由32题推断普遍能力，也没有证明训练数据未包含这些公开题。
  • 原生辅助阶段有88次提出其他模型请求，被实验代理显式统一为DeepSeek并记账；这不证明产品已原生全流程锁模。
  • 早期V1因实验文件隔离配置错误已整批作废。修正后所有对象按V2重跑，不只重跑失败题，不择优拼表。
  • 本页仅发布汇总与方法；不公开原题、答案、原始会话、私有源码、内部地址或凭据。
实际用量，不把 token 当付款金额

有效V2作者运行共4594次模型请求；已报告输入114,636,029 token、输出2,341,058 token，102次请求缺完整用量。输入包括重复历史和缓存，不等于新增信息或实际支付。

此数不含作废批次、全部早期预检、工具服务和裁判的额外消耗。数据下载保留每个对象的用量与未知数，不用缺失值冒充零成本。

军团要成为怎样的战队？

不是把很多名字放进一个下拉框。是让不同 Harness 保留自己的长处、共享工具与现场，能补位，也能从彼此的工作里变强。

方向：按任务组强队

先看到全部可用成员、工具和真实能力，再选适合本题的组合。简单题不强拉全员，复杂任务不漏掉能帮忙的成员。

“找到最好的”是目标，不是未经证明的能力保证。默认选队的实际变更和验收会另外说明。

下一轮：更难，也更多类型

继续查找至少10类高难基准，覆盖不同能力，再用同条件比较。数据版本、样本量、附件和运行限制一起公开。
