除了测分，这次真正改好了什么？

自动组队，不再预先写死一个名字

从完整候选与能力事实自主选择，不永久绑定上次评测第一名，也不每题强制全员重复答题。

明确选人仍保留；“全部候选可见”不等于全部成员已安装、配好或已经参战。

修正“规划员不能写，工人也不能写”的误传

规划进程保持只读；后续作者权限仍由原执行路径检查，不把规划器限制误投成作者禁写。

从原生 DSH 提交，作者实际生成文件，再点击正式下载并读回校验。未由维护者代写成果。 实际文件 41,268 字节。

本机当前 DSH profile 与独立核心，不代表云端及全部公开安装已升级。 本次重放也明确回交了失败事实；不把它包装成单变量模型实验或无人自主完成全部改进。

公开什么，不公开什么

公开全部对象的汇总、样本数、版本、许可、执行条件和未知项。 原题、标准答案、私有会话、原始回复与模型凭据不随网页上传。

默认组队的机制升级与本轮冻结版本评测分开记录。没有做受控新旧版本对比，就不声称升级已带来提分。
