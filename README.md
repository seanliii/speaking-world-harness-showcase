# Speaking Worlds：四家英语互动原型

仅发布可试玩作品，不包含私人聊天、实验轨迹、模型凭据或服务端推理。

## 运行

`python3 -m http.server 8080 --directory docs --bind 127.0.0.1`

GitHub Pages 从本分支 `/docs` 发布；Railway 可直接使用根目录 Dockerfile，通过 `PORT` 监听，不需要数据库或模型密钥。

## 能力边界

- **Legion / Sound Seed Island**：岛屿探索、角色互动、场景动画与本地规则反馈。在线模型对练未接通。
- **Orca / Pip’s Speaking World**：三段情境任务、浏览器语音识别和卡片／文字退路；反馈主要基于规则。
- **Paseo / Pip’s Speaking World**：故事场景、引导表达、录音回放与预制故事短片；刷新后录音不会保留。
- **HarnessRouter / Space Mail Mission**：太空送信任务与语义规则互动；没有浏览器语音识别时只能录音回放，不能完成语义任务。

公开版 Legion 明确禁用了原有私人 `/api/dialog` 通路；原作者工程未修改。公开副本统一加入内容安全策略和说明，原内容、视觉与交互没有另行重做。

仅供原型试玩，不是已验证有效的教学产品。麦克风由你主动授权；浏览器语音识别可能使用浏览器厂商的在线服务，请勿输入真实儿童身份资料。本发布包不含私人对话、公司凭据或收费模型接口。

这是实验原型快照，不提供教学效果、长期服务、商用素材许可或全部浏览器兼容性的保证。自动生成的素材随作品展示，不据此授予第三方额外素材使用权。
